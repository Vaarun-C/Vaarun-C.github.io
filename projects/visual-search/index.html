Everything here runs in this page. Each item gets a 24-number vector: colour (14 hue/neutral bins), type (6), pattern (4). Search is cosine similarity over those vectors, then facet filters, then a colour-token rerank and a brand+type dedupe. The real service uses Titan image embeddings and a Typesense vector index; those are not called here. Fictional brands and products only.
